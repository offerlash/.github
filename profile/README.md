Offerlash helps shoppers discover real coupons, browse stores, and reach the app through a bilingual Arabic and English experience.

## Product Surfaces

**Mobile app**

The Offerlash app is built with Kotlin Multiplatform and Compose Multiplatform for Android and iOS. It supports store discovery, personalized coupon timelines, search, coupon submission, referral attribution, push notifications, and English/Arabic layouts.

**Web**

The Offerlash web experience is built with Next.js, React, and TypeScript. It serves localized public pages, app-download flows, public engagement endpoints, SEO routes, and operational health/readiness checks.
